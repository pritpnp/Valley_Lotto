{# A scan field that behaves the way a retail gun needs it to. Shared by the back-room screens. Set `scan_url` before including, and define `window.onScanResult(data)` in the page to react to each scan. Two things it gets right, both learned the hard way on a phone: the field stays FOCUSED (a gun's keystrokes only reach a focused element, so an unfocused div silently swallowed every scan), and it carries inputmode="none" so Android doesn't raise the soft keyboard for it. #}
