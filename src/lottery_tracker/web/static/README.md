# Brand assets

## logo

Put the real logo in this folder as **`logo.png`** (or `.svg` / `.webp` / `.jpg`).
The header picks it up automatically — no code change, no redeploy config.

- Square works best (the header renders it at 32×32).
- A transparent PNG or an SVG looks cleanest against both the light and dark themes.

Until a file is present, the header falls back to a drawn version of the mark so
it is never a broken image.
